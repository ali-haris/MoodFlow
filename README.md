**Event:** Qloo LLM Hackathon (Devpost)  
**Goal:** Build an AI-powered application that uses Qloo’s API in a novel way  
**Focus:** Emotion-aware discovery using large language models 

🔗 **Live App:** https://moodflow.streamlit.app

---

## 🌟 Overview

**MoodFlow** is an AI-powered emotional intelligence system that transforms how people discover content.

Instead of relying on static recommendation categories (e.g., *sad → drama*), MoodFlow understands emotional context, dynamically generates discovery intent using large language models, and delivers deeply personalized recommendations using the **Qloo API**.

It bridges **psychological understanding**, **AI reasoning**, and **real-world content discovery** into a single, interactive experience.

---

## 🧠 Inspiration

Traditional recommendation systems fail to understand *why* a user feels a certain way.  
They rely on rigid labels and fixed mappings that ignore emotional nuance.

MoodFlow was inspired by a simple question:

> **What if AI could understand your emotional state and generate completely new discovery logic tailored just for you?**

Rather than choosing from pre-defined categories, MoodFlow creates its **own content discovery logic in real time**, adapting to the user's emotional needs.

## 🚀 What MoodFlow Does

MoodFlow allows users to:

## ⚙️ How It Works

MoodFlow follows a fully dynamic, AI-driven pipeline that adapts to each user’s emotional state in real time.

### Step-by-Step Flow

1. **User Describes Their Mood**
   - Natural language input (e.g., *“I feel overwhelmed but hopeful”*)

2. **AI Emotional Analysis**
   - GPT-4 analyzes emotional tone, energy level, and psychological needs

3. **Dynamic Tag Generation**
   - AI selects the most relevant Qloo tags based on emotional intent  
   - No static mappings or predefined categories

4. **Qloo API Querying**
   - Tags are used to fetch personalized recommendations across domains

5. **AI-Generated Emotional Summary**
   - A human-like explanation connects content to the user’s emotional state

6. **Personalized Results Display**
   - Movies, music, books, podcasts, and destinations shown with context
